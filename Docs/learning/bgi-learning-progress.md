# BGI 学习进度追踪（供任务读取与验收）

本文件是**唯一权威进度源**。任何新任务在开始前先读本文件，不要凭对话记忆推断进度。

## 0. 新任务读取指引

1. 读本文件的「当前快照」与「阶段清单」，确认 `current_stage`。
2. 只处理 `current_stage` 及其前置未完成项；不要跳阶段。
3. 用户的产出需要**证据**才能勾选；没有证据只能标 `进行中`。
4. 更新本文件时：只追加「进度记录」行、只勾选 checkbox、更新 `last_updated` 与 `current_stage`；**不修改历史行**。
5. 完成后把结果写回本文件并推送，不要只在对话里说明。

## 1. 状态定义

| 状态 | 含义 | 允许的操作 |
|---|---|---|
| `未开始` | 未动手 | 只能改为 `进行中` |
| `进行中` | 已动手，产出未达标 | 补齐产出后可改 `已完成` |
| `已完成` | 全部必做项勾选 **且** 证据字段非空且可复现 | 只能追加记录 |
| `阻塞` | 缺环境/权限/外部输入 | 需在进度记录写明阻塞原因与解除条件 |

勾选规则：checkbox 只有在证据字段填好后才能勾。

## 5. 验证规则（供验收任务使用）

一个阶段可标记 `已完成`，必须同时满足：

1. 该阶段全部 checkbox 已勾选；
2. `evidence=` 字段非空，且指向真实存在的路径/commit/日志；
3. 证据可由第三方复现（提供命令或操作步骤）；
4. 未修改历史记录行。

不满足任一条 → 保持 `进行中`，并在 `进度记录` 写明缺什么。
