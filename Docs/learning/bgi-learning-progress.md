# BGI 原项目学习进度追踪（供任务读取与验收）

本文件是**唯一权威进度源**。新任务开始前先读它，不要凭对话记忆推断进度。

## 0. 新任务读取指引

1. 读「当前快照」与「阶段清单」，确认 `current_stage`。
2. 只推进 `current_stage` 及其前置未完成项，不跳阶段。
3. 用户的产出需**证据**才能勾选；无证据只能标 `进行中`。
4. 更新规则：只追加「进度记录」行、只勾选 checkbox、更新 `last_updated` 与 `current_stage`；**不修改历史行**。
5. 完成后写回本文件并推送，不要只在对话里说明。

## 1. 状态定义

| 状态 | 含义 | 允许的变更 |
|---|---|---|
| `未开始` | 未动手 | 只能改为 `进行中` |
| `进行中` | 已动手，产出未达标 | 补齐后可改 `已完成` |
| `已完成` | 必做项全部勾选且证据可复现 | 只能追加记录 |
| `阻塞` | 缺环境/权限/外部输入 | 在进度记录写明原因与解除条件 |

规则：checkbox 只有证据字段填好后才能勾选。

阶段标记 `已完成` 必须同时满足：

1. 该阶段全部 checkbox 已勾选；
2. `evidence=` 非空且指向真实存在的路径、commit 或日志；
3. 证据可由第三方复现（提供命令或操作步骤）；
4. 未修改历史记录行。

不满足任一条 → 保持 `进行中`，并在「进度记录」写明缺项。
